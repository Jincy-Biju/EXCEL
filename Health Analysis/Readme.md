 HR Analytics Dashboard – Employee Attrition Analysis

 Project Overview
This project focuses on analyzing employee attrition and workforce trends using Microsoft Excel. An interactive HR Analytics Dashboard was developed to present key insights into employee demographics, department-wise attrition, age groups, education levels, and job satisfaction.

Objectives
- Analyze employee attrition and active employee counts.
- Understand attrition patterns across departments and education levels.
- Explore workforce distribution by age group and gender.
- Identify HR trends through interactive visualizations.
- Present insights to support data-driven decision-making.

Tools & Technologies
- Microsoft Excel
- PivotTables and PivotCharts
- Excel formulas
- Data visualization and analysis

 Key Features
- Employee and attrition KPI metrics
- Department-wise attrition analysis
- Age-group and gender analysis
- Education-level analysis
- Job satisfaction analysis
- Interactive dashboard for exploring HR data

Dataset
The dataset contains 1,470 employee records with information about employee demographics, departments, job roles, education, job satisfaction, and attrition status.

 Key Findings
- Total employees: 1,470
- Employees who left: 237
- Active employees: 1,233
- Overall attrition rate: 16.12%

 Project Outcome
This project demonstrates the use of Excel for data analysis, KPI reporting, and dashboard development. It helps transform raw employee data into meaningful insights that can support HR decision-making.
